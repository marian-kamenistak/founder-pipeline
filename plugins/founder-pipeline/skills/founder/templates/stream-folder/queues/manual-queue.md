# Manual queue — {stream}

General actions only the owner can do that serve neither link acquisition nor media/content (payments, filings, legal/admin, tool access, approvals of non-publish decisions). Purpose decides the queue, not the action type: a registry/directory sign-up whose point is a backlink → `backlink-queue.md` `owner: <owner>`; a platform login for publishing → `media-queue.md` `owner: <owner>`. Checkpoints re-surface all three queues (count + oldest age + highest-value next).

Row format: `- [ ] added YYYY-MM-DD | action (est. min) | ready artifact: <path> | unblocks: <outcome>`
Rule: "drafted, awaiting the owner" = OPEN item. Open ≥ 14 days → do / delegate / kill decision at next checkpoint.
