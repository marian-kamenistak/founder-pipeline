# P1.S7 — Service name + description → `P1-Ideation.S7-Name.md`

**Phase: P1-Ideation** (closes the phase)

**Routing:** judge panel + fan-out (parallel domain/trademark collision agents) · sweeps CHEAP, name judge panel PEAK · gate critic on the session model

**Earns its keep when** the offer needs to land in a crowded category, or when the name signals the positioning.

**Becomes performative when** an obvious natural-language name exists ("Platform Team AI Workshop"). Use it and move on.

**Hard rule:** This step cannot run before P1.S2–S6 (including P1.S4) are complete and approved. Naming before problem-understanding locks thinking around the label. The skill blocks this.

**Mandatory naming input:** P1.S4's Reframe findings (`P1-Ideation.S4-Prediction.md` — demand hiding under different phrasing). Every candidate is checked against the phrasings the market actually uses; a name that fights the reframed demand language loses.

**Grill pass first** (`references/grilling.md`): map this step's decisions and what depends on what, look up every fact in the intake, `brief.md` and approved step files instead of asking, then ask only the open decisions, each with a recommended answer. Play the answers back and get a yes before drafting.

**Ask one at a time:**
1. Three name candidates — for each: one-line rationale + what it signals + what it costs (e.g., narrow vs broad).
2. Which one does the ICP "get" without explanation?
3. Tagline — 5–7 words, captures the unique value.
4. One-line description for cold context (LinkedIn bio length).
5. One-paragraph description for warm context (cold email open).

**Skills:** `/brainstorm` for candidate generation; `/brand-voice` for the tagline and descriptions (they're external-facing copy); a domain-registration-status check across the shortlist (a WHOIS lookup from whatever data provider you configured — DataForSEO's `/v3/domain_analytics/whois/overview/live` is the worked example — or a registrar's own lookup); `WebSearch` for trademark / brand collisions.

**Language note:** check every candidate in every language of the markets declared at P1.S1 — pronunciation, connotations, and how it reads inside a sentence in that language, not just standing alone on a logo. (Worked example: a Czech home market means checking that the name declines readably in Czech and carries no unintended meaning.)

**Trademark authority:** if the collision/trademark sweep blocks a name (or its domain), **change the business name and/or domain without waiting** — including mid-overnight-run. Pick the best surviving candidate, record the old→new mapping + the collision evidence, cascade the rename through every stage file and asset, and flag the change prominently in the morning review. A blocked name is a defect to fix, not a decision to park.

**Trademark registration (explicit step):** once the name is locked, **register the trademark in the right territory** — the territory declared at P1.S1, not wherever filing happens to be cheapest. Two routes, and the market picks between them: a **national mark** at your home country's industrial-property office when the market is that one country, or a **regional / multi-country mark** when the ambition crosses borders.

> *Worked example (Czech home market):* CZ-only → national mark at ÚPV (Úřad průmyslového vlastnictví, roughly 5,000 CZK base); EU-wide ambitions → an EUTM at EUIPO (roughly €850 for one class, with classes 35 and 41 the usual pair for services and education). Look up the equivalent office, fee schedule and class numbers for your own territory — the structure transfers, the numbers do not.

Action items into the roadmap: (1) proper clearance search (a lawyer, or the office's own trademark database — the web sweep is a pre-filter, not clearance), (2) file the application with owner + date, (3) register the matching domains same-day. Cost lands in `P2-Viability.S1-Economics.md` upfront, in the currency declared at P1.S1. Overnight runs prepare the filing spec (name, classes, territory, owner entity); the actual filing is the owner's click.

**Write to** `P1-Ideation.S7-Name.md`. Include all 3 candidates + pros/cons, mark the pick, drop the loser rationale. Record per-candidate WHOIS status (available/registered + evidence line) and the collision sweep log for ALL candidates — queries run, dates, result (clean/hit) — not only when a name is blocked.

**Def-of-success — ALL must pass before owner sign-off (fail → improvement loop per SKILL.md, never advance):**
- `/critical` run recorded; the score is advisory (target ≥ 8/10) — the gate is the PASS/FAIL criteria below, not the number.
- 3 candidates each with rationale + signal + cost.
- Picked name passes "ICP gets it without explanation" — gut-checked with 2 real ICPs; skipping the gut-check requires the owner's explicit recorded override (PROGRESS.md note), never a model-written "why skipped".
- WHOIS status recorded PER candidate in the output file (available/registered + evidence line); the picked name's primary domain is available or owned BEFORE lock — otherwise rename per the trademark-authority rule.
- Collision sweep log for ALL candidates — queries run, dates, result (clean/hit) — recorded in the output file, not only when a name is blocked.
- Tagline ≤ 7 words; name signals the P1.S5 positioning, not just aesthetics — and respects P1.S4's Reframe phrasings.
- Language check done in EVERY language of the markets declared at P1.S1 (pronunciation, connotation, how it reads inside a sentence in that language) — a name checked only in English while the home market speaks something else FAILS.
- **Trademark filing spec exists** (territory, classes, owner entity, cost fed to P2.S1) — and if any candidate was trademark-blocked, the rename was executed, not parked.

**Gate out (mandatory — see SKILL.md house rules):**
1. Draft `P1-Ideation.S7-Name.md`.
2. Invoke `/critical` on the draft — does the picked name actually signal the P1.S5 positioning, or just sound good? What does it cost?
3. Revise; note what changed.
4. Present the draft + the critical findings + the changes to the owner. **Wait for their explicit approval. Never auto-advance.**

**Checkpoint:** "Locked name: [X]. Tagline: [Y]. P1-Ideation phase complete. Moving to P2-Viability — or do you want to gut-check the name with 2 ICPs first?"
