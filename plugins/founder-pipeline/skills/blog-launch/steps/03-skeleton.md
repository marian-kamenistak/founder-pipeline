# Step 03 — Skeleton

Main loop, session model, high effort. Load `references/writing-style.md` now; it governs this step and step 04.

## Compose `skeleton.md`

1. **Headline** — pick from the 3 research candidates (or beat them). Subtitle = the meta description seed.
2. **Cold open plan** — the first 3 paragraphs: which contrarian claim, which number leads, where the personal story enters. No wind-up, no "in this post I will".
3. **Section list** — opinionated H2s (sentence-like, position-taking: "ROI or it didn't happen", not "Measuring Impact"). For each H2: the one idea, the evidence planned (number/name/date + source URL), any counter-voice to cite and rebut. **H1 is the page title only** — it comes from frontmatter and the template renders it once; the body never contains a markdown `#`. Any subdivision inside an H2 is H3, deeper still is H4 — one level at a time, never skipped, never dropped back to H1.
4. **Spine check** — the sections must cover Problem → Solution → How to get there → Lessons learned, in whatever order serves the story. Definition or the post's core number lands in the **first 60 words**, always — AI search engines lift the opening block, not paragraph 3 (evidence: `/founder-pipeline:ai-seo` Pillar 1 + GEO-SFE's +17.3% structure-only result). Definitional-keyword posts additionally: a data table planned now (item 5), FAQ candidates (item 7).
5. **Readability design plan** — where the **data table** goes (a rate table, a scope/segment table, or a straight comparison — always plan one; AI search engines extract tables near-verbatim), which single sentence becomes the pull-quote/highlight, where the 1-2 images sit (slot by `kind`: talk/mentoring/portrait), where bold lead-ins carry a list. A wall of same-shaped paragraphs is a design failure; plan the visual rhythm now.
6. **Internal links** — 2-4 money pages + 1-3 previous posts (site profile lists them). Which anchor text, in which section.
7. **FAQ candidates** — 3-5 PAA-phrased Q&As from the research's AI-answer targets (→ `faqs` frontmatter).
8. **What this post deliberately does NOT say** — scope fence, keeps the draft tight.

## Checkpoint (FYI, non-blocking)

Post the skeleton + chosen headline to the owner as FYI and continue immediately to steps 04 ∥ 05. If they object later, the revise loop absorbs it. (In step-by-step conversations they'll usually react before the draft lands; in "run it through" mode this is just a log line.)
